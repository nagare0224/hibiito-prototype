# HIBIITO Visual Prototype Hub

HIBIITOの非canonicalなVisual Prototype確認用リポジトリです。

## 目的

- HumanがスマホのURLから画面デザインを確認する
- 実装前にfont / spacing / component比率 / Day-Night / long-copy / image compositionを調整する
- production specやAndroid実装のSource of Truthにはしない

## 公開境界

このrepositoryはPublicです。以下を置きません。

- raw health data
- secret / token / credential
- private screenshot
- product source code
- Humanがpublic化を承認していないproduction asset

Prototypeはdummy dataのみを使用します。
