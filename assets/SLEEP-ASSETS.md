# Sleep calm v2 assets

今回の3点は組み込み画像生成機能で新規作成したoriginal候補です。外部画像・private screenshot・production素材を入力・転用していません。Humanのpublic-safe素材の新規生成・公開依頼に基づき配置しています。

- `sleep-hero-day-morning-v2.webp`: 淡い朝空、湖、植物。Hero専用、キャラクターなし。
- `sleep-hero-night-lake-v2.webp`: 静かな月夜と湖。Hero専用、キャラクターなし。月は画像内の1つだけ。
- `sleep-note-mascot-resting-v2.webp`: 透過の眠る芽のマスコット。ひとことカード専用。

ファイルのhash、生成指示の要約、変換条件は `sleep-calm-v2-manifest.json` を参照。生成モデル名・creditsは観測できないため記録しません。Usage: Unverified — usage telemetry unavailable。

元のSVG素材はrollbackと比較用に保持しています。既存の `sleep-garden.svg` は端の補助装飾に使用しています。新規画像はWebPへ圧縮しただけで、private情報やUI文字は含みません。今後の実装でも再利用できますが、prototype採用はproduction Visual Contract確定を意味しません。
